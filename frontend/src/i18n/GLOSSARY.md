# i18n Terminology Glossary

Bắt buộc dùng thống nhất khi dịch. Cột **VI** và **EN** là giá trị chuẩn.
EN theo hướng **mô tả** (không dùng pinyin trần).

## Genres (thể loại truyện)
| zh | VI | EN |
|----|----|----|
| 玄幻 | Huyền huyễn | Eastern Fantasy |
| 都市 | Đô thị | Urban |
| 历史 | Lịch sử | Historical |
| 科幻 | Khoa huyễn | Sci-Fi |
| 武侠 | Võ hiệp | Wuxia / Martial Arts |
| 仙侠 | Tiên hiệp | Xianxia / Immortal Heroes |
| 奇幻 | Kỳ huyễn | Fantasy |
| 悬疑 | Huyền nghi | Mystery |
| 言情 | Ngôn tình | Romance |
| 修仙 | Tu tiên | Cultivation |

Ghi chú phân biệt: 玄幻 = fantasy rất rộng; 仙侠 = fantasy "tiên + đạo + kiếm hiệp"; 修仙 = tập trung quá trình tu luyện.
